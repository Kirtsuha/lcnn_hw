# LCNN voice anti-spoofing

This repository contains my solution to the ASVspoof 2019 Logical Access
homework. The goal is to distinguish bona fide speech from speech generated by
text-to-speech or voice-conversion systems.

The final model achieves **7.9114% EER** on all 71,237 utterances of the
official LA evaluation split. The supplied grading script gives it a
performance score of **6.27** before the PyTorch Project Template bonus.

- [W&B training report](https://api.wandb.ai/links/batukhtin-kir-hse-university/woaavkiv)
- Final submission: `kebatukhtin.csv`
- Full run: `kaggle-lcnn-stft-ce-balanced-seed-1`

## What the system does

The project is a binary speech classifier built around Light CNN (LCNN). Each
recording goes through the following pipeline:

```text
FLAC → 16 kHz mono → log-power STFT → LCNN → spoof/bonafide logits
```

The frontend uses a 512-point FFT, a 320-sample Hann window and a 160-sample
hop. Every example is represented by 257 frequency bins and 750 frames. Long
training recordings are cropped randomly; development and evaluation crops are
deterministic.

LCNN uses Max-Feature-Map activations: pairs of feature maps compete through an
element-wise maximum. The network has 3,926,818 trainable parameters. Following
the homework requirement, dropout with probability 0.75 is placed immediately
before the final batch-normalization layer. The task-specific LCNN was
implemented from the architecture descriptions in the assigned papers rather
than copied from an available implementation.

Cross-Entropy was used as a stable baseline objective. The training split is
strongly imbalanced—22,800 spoof examples versus 2,580 bona fide examples—so a
`WeightedRandomSampler` gives both classes equal expected sampling probability.
I did not combine the balanced sampler with class-weighted Cross-Entropy, which
would compensate for the same imbalance twice.

## Experimental setup

| Parameter | Value |
|---|---:|
| Dataset | ASVspoof 2019 LA |
| Train / dev / eval size | 25,380 / 24,844 / 71,237 |
| Input | 16 kHz mono, log-power STFT |
| FFT / window / hop | 512 / 320 / 160 samples |
| Input tensor | 1 × 257 × 750 |
| Model | LCNN with Max-Feature-Map |
| Loss | Cross-Entropy |
| Optimizer | Adam |
| Initial learning rate | 3 × 10⁻⁴ |
| Scheduler | StepLR, ×0.5 every 4,000 steps |
| Batch size | 16 |
| Training | 30 epochs × 400 steps |
| Seed | 1 |
| GPU | NVIDIA Tesla T4 |
| Training time | 1.6536 hours |
| Checkpoint selection | Minimum full-development EER |

The experiment was run through the template's `train.py`; W&B logging,
configuration saving and checkpointing were part of the same process. The
official evaluation split was not used for hyperparameter tuning or checkpoint
selection.

## Pipeline checks

Before full training, I ran a one-batch test on eight fixed examples. After 200
steps the model reached loss `0.0007748472`, accuracy `1.0` and EER `0.0%` on
that batch. This checked the whole path from audio loading to checkpoint
restoration.

I then compared natural and balanced sampling under the same short-run setup:

| Sampling | Development EER on diagnostic subset |
|---|---:|
| Natural | 19.6% |
| Balanced | 0.0% |

These subset results are diagnostics, not final quality estimates. They were
used only to choose the sampling strategy before the full run.

## Training results

Training loss falls quickly during the first part of the 12,000-step run and
then remains close to zero. The occasional spikes are visible because the
curve is plotted without smoothing.

![Training loss](homework-report/figures/train_loss.png)

Development loss was calculated on the complete development split after every
epoch. Its final value is `0.000211569`.

![Development loss](homework-report/figures/dev_loss.png)

Equal Error Rate is the main metric. It is the operating point where false
rejection and false acceptance rates are closest; lower is better. Development
EER first reached `0.0%` at epoch 12. The final selected checkpoint is from
epoch 24—the last epoch that matched the best development EER.

![Development EER](homework-report/figures/dev_eer.png)

Development accuracy reached `0.999960` at the end of training. The vertical
axis is intentionally zoomed to 0.95–1.00 because all 30 full-development
measurements lie in that narrow range.

![Development accuracy](homework-report/figures/dev_accuracy.png)

## Final evaluation

The epoch-24 checkpoint was applied once to the complete official LA evaluation
split. The resulting headerless CSV contains every protocol ID exactly once,
with a larger score indicating stronger support for bona fide speech.

| Result | Value |
|---|---:|
| Best development EER | 0.0000% |
| Final development EER | 0.00224255% |
| Final development accuracy | 99.9960% |
| Full evaluation EER | **7.9114%** |
| Performance score before template bonus | **6.27** |

The supplied `grading.py` completed successfully on `kebatukhtin.csv`. No
alternative checkpoint or configuration was chosen after seeing the evaluation
result.

The large difference between development and evaluation EER is the main
limitation of the model. The evaluation split contains attack conditions that
were unavailable during model selection. For context, the STC systems reported
1.86% LA evaluation EER, while the best single model in the comparative study
reported 1.92%. Those systems used different frontends, objectives and
experimental budgets, so the numbers are not directly comparable, but they
show that a simple Cross-Entropy baseline leaves room for better
generalization.

## Installation

Python 3.10 or 3.11 is recommended. On Kaggle or another GPU environment, keep
the preinstalled compatible PyTorch and torchaudio builds when appropriate.

```bash
git clone https://github.com/Kirtsuha/lcnn_hw.git
cd lcnn_hw
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
python3 -m pip install -r requirements.txt
pre-commit install
python3 -m pytest
```

## Dataset layout

The ASVspoof data are not included in Git. Training and inference expect:

```text
/path/to/asvspoof/
├── ASVspoof2019_LA_train/flac/*.flac
├── ASVspoof2019_LA_dev/flac/*.flac
└── ASVspoof2019_LA_eval/flac/*.flac

/path/to/protocols/
├── ASVspoof2019.LA.cm.train.trn.txt
├── ASVspoof2019.LA.cm.dev.trl.txt
└── ASVspoof2019.LA.cm.eval.trl.txt
```

## Running the project

One-batch test:

```bash
python3 train.py -cn=lcnn_one_batch \
  data_dir=/path/to/asvspoof \
  protocol_dir=/path/to/protocols
```

Full training:

```bash
python3 train.py -cn=lcnn \
  data_dir=/path/to/asvspoof \
  protocol_dir=/path/to/protocols \
  train_sampling=balanced \
  writer.run_name=lcnn-stft-ce-balanced-seed-1
```

Inference:

```bash
python3 inference.py -cn=lcnn_inference \
  data_dir=/path/to/asvspoof \
  protocol_dir=/path/to/protocols \
  inferencer.from_pretrained=/absolute/path/to/model_best.pth
```

Inference writes `data/saved/submission/eval.csv` with two columns and no
header:

```text
utterance_id,bonafide_logit
```
